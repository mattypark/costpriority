Drop your own pet drawing in here as pet.png.

  • PNG with a transparent background works best.
  • Any size — the pet scales to the width you pick in its menu (Pet size),
    and takes its height from your image's own proportions. Something around
    512px on the long edge is plenty.
  • Easiest route: click the pet -> "Choose sprite…" and pick the file. It gets
    copied in here for you, and the pet redraws immediately.

Per-theme sprites (optional)
  A file named pet-<theme>.png is used whenever that theme is active, falling
  back to pet.png otherwise. The theme ids are:

    claude   midnight   mono   ember   forest   plum   sand   matrix

  So pet-matrix.png would only show up under the Matrix theme.

The pet.png shipped here is a placeholder. Replace it.
